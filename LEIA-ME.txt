SITE DO ACOLHER — VERSÃO PARA GITHUB PAGES
=========================================

Esta pasta já está pronta para publicar: são páginas HTML estáticas, sem build, sem dependências.

Arquivos
- index.html            → página inicial
- funcionalidades.html  → funcionalidades
- planos.html           → planos e preços
- styles.css            → visual do site (compartilhado pelas 3 páginas)

Como publicar no GitHub Pages
1. Crie um repositório no GitHub e envie estes 4 arquivos.
2. No repositório: Settings → Pages.
3. Em "Build and deployment", escolha "Deploy from a branch".
4. Branch: main · Folder: / (root) e salve.
5. Em alguns instantes o site fica no endereço https://SEU-USUARIO.github.io/NOME-DO-REPO/

Observações
- Os links entre as páginas são relativos (./pagina.html), então funcionam tanto na raiz
  do domínio quanto dentro de uma subpasta do GitHub Pages.
- Os botões de app ("Baixar o app", "Entrar", "Cadastro") apontam para
  https://acolher-gestao-emocional.base44.app — troque esse endereço se usar um domínio próprio.
- As imagens são carregadas por URL completa, então funcionam de qualquer hospedagem.
